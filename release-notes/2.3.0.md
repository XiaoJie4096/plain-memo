# PlainMemo 2.3.0

## 改动

- 编辑器升级为 CodeMirror 6，改善输入、光标、选区、撤销重做和编辑稳定性。
- 编辑时支持标签、图片、无序列表、有序列表和任务列表的所见即所得显示。
- 新增任务列表按钮，并支持 Ctrl+L / Cmd+L 快捷键。
- 优化列表输入、换行、退出和退格行为，兼容手机端输入法及全角有序序号。
- 优化标签候选的显示、选择、确认和再次触发行为。
- 修复切换编辑、保存和后台同步时，编辑内容、光标或提交状态可能不同步的问题。
- 优化编辑器中的列表和任务列表样式。
- 修复同步过程中笔记短暂消失时，置顶状态可能被误取消的问题。
- 优化过长中文标题生成的文件名，降低移动端同步时触发文件名长度限制的风险。
- 在 `PlainMemo/picture` 中添加 Android 媒体扫描屏蔽标记，避免受管理图片出现在系统相册中。
- 补充 CodeMirror 6、Lezer 及相关依赖的第三方版权与 MIT 许可证声明。

## Changes

- Upgraded the editor to CodeMirror 6 for more reliable input, cursor movement, selection, undo/redo, and editing stability.
- Added WYSIWYG support for tags, images, unordered lists, ordered lists, and task lists while editing.
- Added a task-list button and Ctrl+L / Cmd+L shortcuts.
- Improved list input, line breaks, exit, and backspace behavior, including mobile IME input and full-width ordered-list markers.
- Improved tag suggestions, selection, confirmation, and retriggering behavior.
- Fixed possible synchronization issues with editor content, cursor state, and submission state when switching, saving, or syncing in the background.
- Improved list and task-list styling in the editor.
- Fixed pinned memos being incorrectly unpinned when a memo temporarily disappeared during synchronization.
- Improved filename generation for very long Chinese titles to reduce mobile synchronization filename-length failures.
- Added an Android media-scan exclusion marker in `PlainMemo/picture` so managed images do not appear in the system gallery.
- Added third-party copyright and MIT license notices for CodeMirror 6, Lezer, and related dependencies.
