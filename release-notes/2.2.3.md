# PlainMemo 2.2.3

## Changes

- Adjusted parts of the interface.
- Improved mobile navigation, back behavior, and bottom button layout.
- Improved long-memo collapsing and expanding. Long paragraphs without line breaks can now collapse correctly.
- Added recognition, rendering, and filtering for numeric tags.
- Fixed new-memo drafts and their images potentially being lost when switching to edit another memo.
- Fixed Android Back from tag and trash pages potentially triggering Obsidian's exit prompt.
- Fixed the mobile title dropdown and search button display.
- Improved spacing between the mobile floating collapse button and the new-memo button.

---

## 改动

- 调整了部分界面。
- 优化移动端导航、返回交互和底部按钮布局。
- 优化长笔记的折叠与展开交互，现在无换行的长段落也能正常折叠。
- 支持纯数字标签的识别、渲染与筛选。
- 修复切换编辑笔记时，新建笔记草稿和其中图片可能丢失的问题。
- 修复手机端标签页、回收站页面返回时可能触发 Obsidian 退出提示的问题。
- 修复手机端标题下拉菜单和搜索按钮的显示问题。
- 优化手机端悬浮收起按钮与新增按钮的间距。
