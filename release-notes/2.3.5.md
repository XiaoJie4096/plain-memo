# PlainMemo 2.3.5

## 改动

- 修复 Android 上在有序列表、无序列表和任务列表中续写时，首个输入字符可能丢失的问题。
- 稳定 Android 编辑器中的列表序号、圆点和复选框，避免光标移动时列表标记和正文间距跳动。修复列表内按回车或退格时编辑区可能滚回顶部的问题。
- 统一笔记卡片和编辑器的排版。卡片区分段内换行、分段和原文空行的间距，编辑器保留原始 Markdown 中的空行。

---

## Changes

- Fixed an issue on Android where the first typed character could be dropped when continuing an ordered, unordered, or task list.
- Kept list numbers, bullets, checkboxes, and text spacing stable as the cursor moves in the Android editor. Fixed an issue where pressing Enter or Backspace in a list could scroll the editor back to the top.
- Aligned typography between memo cards and the editor. Cards distinguish between line breaks, paragraph breaks, and blank lines in the source, and the editor preserves blank lines in the original Markdown.
