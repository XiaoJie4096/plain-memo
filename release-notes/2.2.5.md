# PlainMemo 2.2.5

## Changes

- Added an optional setting to open PlainMemo after Obsidian restores the workspace.
- The setting is local to each device, so desktop and mobile can be configured independently.
- Startup reuses an existing PlainMemo page when available and does not close other tabs.

---

## 改动

- 新增“启动时打开 PlainMemo”可选设置。
- 该设置仅在当前设备生效，桌面端和移动端可分别配置。
- 启动时会复用已有 PlainMemo 页面，不会关闭其他标签页。
